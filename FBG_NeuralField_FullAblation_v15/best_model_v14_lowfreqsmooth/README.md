## 为什么保存 5 个模型

本结果来自工况级五折交叉验证。每一折模型只在该折训练工况上拟合，并对相应
留出工况进行测试，因此不存在一个天然的“唯一五折最佳权重”。本目录保存五个
折模型，确保完整复现报告结果，也可以在兼容输入条件下构成五模型集成。

不要把其中某一折权重称为“使用全部数据训练的最终部署模型”。如果需要单模型
部署，应在结构和超参数冻结后，增加独立的全数据训练入口，并使用新的外部测试集
评估，不能再用本次五折测试结果选择该模型。
