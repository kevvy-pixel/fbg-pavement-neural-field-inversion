## 6. 结构消融结论

| 模型 | 分层 FiLM | 交换不变荷载编码 | 共享主干 + 层残差 | 结论 |
|---|---:|---:|---:|---|
| B0 | 否 | 否 | 否 | 整体稳定基线 |
| B3 | 是 | 否 | 否 | 土层优势，但存在双点顺序敏感性 |
| G2 | 是 | 是 | 否 | 当前主候选，交换严格不变 |
| G3 | 否/残差层头 | 否 | 是 | 沥青层略有改善，但保留顺序敏感性 |
| G2+G3 | 是 | 是 | 是 | 未显示相对于 G2 的明确组合收益 |

## 7. 最终角色

```text
A0-3：确定性时序基线
B0：fixed-test 整体最佳基线
G2：交换不变、layer-aware、土层空间泛化更强的主候选
```

G2 不应被表述为全结构统一最优模型。其主要贡献是去除无物理依据的 `p1/p2` 顺序信息，并改善部分土层和双重外推组合；SAT2 仍是主要沥青层风险点。
