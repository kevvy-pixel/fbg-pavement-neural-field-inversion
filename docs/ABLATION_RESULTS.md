# CorrectedData_v2模型与消融实验

## 统一协议

- 22个独立工况；
- 616个沥青层目标；
- 固定工况五折；
- 测试工况零沥青目标观测；
- 目标为 `delta_lambda_final_nm / 0.0012`；
- 超参数仅在外层训练工况内部选择；
- 统计区间采用工况级50,000次配对Bootstrap。

## 关键消融

### POD输出压缩

POD–RBF为35.286 με，Direct RBF为32.152 με；差值95%区间为 `[0.474,6.540]` με。修正后的28通道响应具有更一致的语义，直接多输出不再需要POD压缩才能稳定。

### 土层辅助

Direct RBF加入土层汇总后为33.087 με，与仅元数据版本的差值区间为 `[-1.585,4.052]` με，没有平均增益。POD–RBF加入土层后退化至46.137 με。

### 锚定专家

修正后Single为39.882、Top3Soil为40.998 με。Top3Soil只在部分折改善，固定使用不再合理。

### 联级门控

修正后的v23门控对21个工况选择Single，只对1个工况切换Top3Soil，且该切换增加误差。联级最终40.262 με，差于固定Single。

### 物理约束

v27 Dynamic Winkler PINN为40.608 με。Mindlin纯物理场为66.118 με；Mindlin残差RBF为32.989 με，但相对主模型差值区间跨零。五折均把Mindlin剪切刚度推到搜索上限，即退化为Kirchhoff极限。

## 模型选择

当前保留：

1. Direct RBF作为持载末期主模型；
2. v19 Single作为连续坐标神经场基线；
3. v27作为强物理残差负消融；
4. Mindlin/Kirchhoff残差作为弱物理候选。

不再把Top3Soil和旧联级门控作为主干。
